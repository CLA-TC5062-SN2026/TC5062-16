# LaundryDesk Frontend

Scaffolding inicial del frontend de LaundryDesk.

## Stack

- React
- Vite
- Bootstrap 5
- React Router
- Fetch API
- Context API / estado local (para etapas posteriores)

## Configuración

1. Copia `.env.example` a `.env`.
2. Verifica que `VITE_API_URL` apunte al backend correcto.
3. Instala dependencias:

```bash
npm install
```

4. Inicia el servidor de desarrollo:

```bash
npm run dev
```

5. Abre en el navegador la URL que muestre Vite.
